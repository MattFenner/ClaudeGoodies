# ClaudeGoodies
Claude plugins and other goodies

## Plugins

### todo-list

A persistent todo list with a panel, a `/todo` command, and a tool Claude can use to manage it. Todos are saved in the plugin's data folder, so they survive plugin updates.

Install it:

```bash
/plugin marketplace add MattFenner/ClaudeGoodies
/plugin install todo-list --marketplace MattFenner/ClaudeGoodies
```
